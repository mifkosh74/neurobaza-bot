# БОТ БАЗА — воронка на «Нейробазу»

Telegram-бот по ТЗ Кристины (гуглдок «БОТ БАЗА», вкладка «Воронка на нейробазу»):
знакомство → бесплатный урок по Seedance → бонус-гайд для промптов через 15 минут → 12 дней прогрева → оффер со старой ценой → финальное напоминание.
Плюс запись на бесплатный разбор (3 вопроса), фиксация старой цены, заявки и вопросы людей Николаю в личку.

Node 22, без зависимостей. Тексты в `content.mjs`, логика расписания в `funnel.mjs`, поведение в `app.mjs`, запуск в `bot.mjs`.

Запущен 23.10.2026 как `bot_1792755804_4908_mifkosh` (Нидерланды). Настройки, с которыми он работает:

1. bothost.ru → «Создать бота».
2. Название — `БОТ БАЗА`; Платформа — Telegram; Библиотека — telegraf (это вариант Node.js; зависимостей у бота нет); образ — node:22 Alpine; Bot Token — токен от @BotFather; Локация — Нидерланды.

4. «Дополнительные настройки»: Главный файл — `index.js`. Собственный Dockerfile не нужен.

Автосборка bothost делает `npm ci`, поэтому `package-lock.json` должен лежать в репозитории (без него сборка падает с EUSAGE).
Обновление кода: `git push` в `main`, затем на карточке бота кнопка «Обновить из Git» (на платном тарифе можно включить автообновление по webhook). Токен и папка с базой сохраняются — проверено 23.10.
Запасной путь без GitHub — архив (тариф «Базовый»/«Pro», в профиле включить «Загрузка бота из архива»):
`git archive --format=zip -o "БОТ_БАЗА_для_bothost.zip" HEAD -- package.json index.js bot.mjs app.mjs funnel.mjs content.mjs store.mjs Dockerfile README.md`.

Токен bothost передаёт в `BOT_TOKEN`/`API_TOKEN`. Переменные окружения не нужны: админ (509801940 = @neurokean) и куда слать заявки прописаны в `content.mjs`.
База пишется в `/app/data/db.json` — эта папка на bothost переживает обновления. Урок и гайды прописаны в `content.mjs` по file_id, заново грузить не надо.

Запасной запуск на компьютере: токен в файл `.token`, двойной клик по `Запустить локально.bat`. Вместе с bothost не запускать.

Загрузить файл с компьютера в слот локальной копии (бот остановлен, файл до 50 МБ):
`node upload.mjs guide_claude "C:\путь\файл.zip"` — файл придёт админу в личку с ботом, его file_id запишется в `data/db.json`.

## Первые 10 минут после запуска (всё из Telegram, в личке с ботом)

1. `/media` — список файлов. Загрузить:
   - `/set lesson_video` → отправить файл урока `УРОК_Seedance_замена_окружения_монтаж_v2_с_работами.mp4` (1,15 ГБ, из Telegram Desktop — до 2 ГБ можно). Или урок на YouTube: `/config lesson_url https://...`
   - `/set guide_claude` → `C:\Клод\Замена окружения SYNTX\seedance-env-swap.zip`
   - `/set guide_chatgpt` → `C:\Клод\Замена окружения SYNTX\ChatGPT_инструкция.txt`
   - по желанию: `hello_circle` (кружок дня 1), `lesson_teaser` (обложка/было-стало), `d3_media`, `d6_media`…
2. `/steps` — какие шаги готовы. Неготовый шаг людям не уходит: человек просто получает следующий день.
3. `/start`, потом `/next` много раз — пройти всю цепочку самому. `/reset_me` — начать заново.
   Дать проверить другому (например, Крис): человек жмёт `/start`, ты пишешь `/tester @его_ник` (ник — в `/users`). Ему станут доступны `/reset_me` и `/next`, остальное управление — нет. Сбросить любого: `/reset @ник`.
4. `/stats` — статистика по входам, уроку, гайду, разборам, источникам.

## Ссылки для входа

`https://t.me/<юзернейм_бота>?start=<метка>` — метка = источник, видна в `/stats` и в заявках.
Примеры: `?start=reels_seedance`, `?start=stories_1023`, `?start=tg_post`. Сайт уже ведёт так: `?start=<место>__<источник>` — в `site/config.js` надо вписать юзернейм в `bot`/`freeBot`.

## Как устроено расписание

- День 1 — в момент входа; дни 2–12 — каждый день в то же время, что и вход, но в окне 10:00–20:00 МСК.
- Одно основное сообщение в день. Ответы на кнопки (урок, гайд, «АГЕНТ001», разбор) приходят сразу.
- Не нажал «Забрать бесплатный урок» до второго дня — на второй день бот присылает урок вместо письма дня 2, дальше всё сдвигается.
- Бонус-гайд — через 15 минут после открытия видео урока (если урок по ссылке — через 15 минут после сообщения с уроком).
- Оффер (день 12) со старой ценой уходит, только пока до повышения больше 3 часов. Если 12-й день человека выпадает на после повышения, оффер приходит раньше: накануне повышения в 12:00 (но не раньше его 3-го дня). Текст тогда начинается «За эти дни…» вместо «За эти 12 дней…».
- Финальное напоминание — в день повышения в 18:00 МСК, только тем, кто получил оффер, не купил и не нажал «Зафиксировать».
- После повышения оффер со старой ценой не уходит никому; цепочка заканчивается днём 11. Новый срок — `/config deadline …`.
- Купивших (`/paid`, кнопка «✅ Купил курс» под заявкой) бот выключает из цепочки, рассылки (`/broadcast`, вариант «Всем») они получают.

## Персональные данные

Как в боте АГЕНТ001: согласие даётся нажатием «Старт». Условия написаны в описании бота (Telegram показывает его в пустом чате до «Старт»), со ссылками на документы сайта: Согласие (neurokean.ru/legal/consent.html) и Политику (neurokean.ru/legal/privacy.html). Описание и команды бот ставит себе сам при каждом запуске (`botProfile` в `content.mjs`).

- При `/start` в карточке человека записывается `consent: {version, at}`, где version — редакция документов (`consent_version`). Поменялась редакция — при следующем `/start` запишется новое согласие.
- `/privacy` — что хранит бот, ссылки на документы, контакт для отзыва согласия.
- `/stop` (или `/unsubscribe`) — бот больше ничего не присылает, ни цепочку, ни рассылки; `/start` возвращает.
- `/delete` — удаляет запись человека из базы бота.

## Заявки и вопросы

- Разбор: «Записаться на бесплатный разбор» → описание → 3 вопроса (+ контакт, если у человека нет ника) → заявка Николаю. Лимит мест в неделю.
- Фиксация цены: выбор тарифа → (контакт) → заявка Николаю, человек помечается «зафиксировал».
- Любое сообщение человека боту пересылается Николаю. Ответ реплаем на пересланное уходит человеку от имени бота.

## Решения, которых не было в ТЗ (на согласование с Кристиной)

- Тексты-ответы: после записи на разбор, выбор тарифа при фиксации цены, «места на неделю заняты», «передал сообщение Николаю» (`replies` и `forms` в `content.mjs`).
- Механика фиксации старой цены: заявка с тарифом Николаю, дальше он пишет лично.
- Ранний оффер накануне повышения и время финального напоминания (18:00 МСК).
- Инструкция по установке гайда (шаг `guide_howto`).
- В тексте дня 8 исправлена опечатка «клиеентов», в дне 10 «Присоедениться».
